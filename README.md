# 🛡️ VASU – AI-Powered Karnataka Crime Intelligence & Analytics Platform

> **Vigilant Analytics for Safety & Urban Intelligence (VASU)** is an AI-powered crime analytics platform developed for the **Zoho Catalyst AI-Driven Crime Analytics & Visualization Challenge**. It helps law enforcement agencies analyse crime trends, identify hotspots, predict future crime patterns, and make data-driven decisions through interactive dashboards and AI-powered insights.

## 📌 Problem Statement

Law enforcement agencies generate massive amounts of crime data every day. Traditional methods make it difficult to identify crime patterns, analyse district-wise statistics, visualise hotspots, and generate actionable insights quickly.

VASU addresses this challenge through AI-driven analytics, geospatial visualisation, predictive modelling, and intelligent reporting.

## ⚙️ Installation



